# Notas SEO técnicas

## Dominio canónico

- Dominio principal: `https://borchgomez.es/`.
- Debe existir una redirección permanente externa de `https://www.borchgomez.es/` a `https://borchgomez.es/`.
- La web pública actual solo expone `/` como ruta indexable.

## Datos pendientes

- Imagen social dedicada en formato 1200x630, si Borja quiere una previsualización Open Graph optimizada.
- Dirección, coordenadas, horario, área formal de servicio y URL de Google Business Profile, si se quiere completar el schema local sin inventar datos.

## Acciones externas

- Verificar propiedad de `https://borchgomez.es/` en Google Search Console y Bing Webmaster Tools.
- Enviar `https://borchgomez.es/sitemap.xml` en los paneles de webmaster.
- Revisar Google Business Profile y enlazarlo con la web si Borja proporciona la URL oficial.
